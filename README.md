## 🎯 Призначення та мета проєкту

Проєкт реалізує інтерактивну Kanban-дошку, оптимізовану для організації навчального процесу студента спеціальності «Комп'ютерні науки / Інженерія програмного забезпечення» у РФКІТ. ## 🚀 Як відкрити та користуватися

1. Відкрийте файл `index.html` у будь-якому сучасному веббраузері (Chrome, Edge, Firefox):
   ```bash
   start rfkit-kanban/index.html
   ```
2. **Перетягування (Drag and Drop):** Затисніть ліву кнопку миші на картці та перетягніть її в потрібну колонку (`To Do` ➔ `In Progress` ➔ `Done`).
3. **Швидкі кнопки:** На кожній картці доступні стрілки `➔` та `⬅` для миттєвого переміщення без перетягування.
4. **Перегляд деталей:** Клікніть на картку для відкриття модального вікна з розширеним описом, зміною статусу та можливістю редагування.
5. **Створення нової картки:** Натисніть кнопку `➕ Додати картку` у верхній панелі або `+` у заголовку будь-якої колонки.
6. **Автоматизоване тестування:** Натисніть `⚡ Протестувати перекидання` — запуститься покрокова симуляція з верифікацією та детальним журналом результатів.

## 🧪 Тестування перекидання карток

У проєкті реалізовано інтерактивний тест-модуль, який перевіряє:
- Початкову кількість карток у колонках (To Do: 4, In Progress: 0, Done: 0).
- Переміщення Картки 1 у колонку «In Progress».
- Переміщення Картки 2 у колонку «In Progress».
- Переміщення Картки 1 у колонку «Done» (фіксація завершення завдання).
- Наскрізний цикл для Картки 3 (To Do ➔ In Progress ➔ Done).
- Збереження та відновлення стану в `localStorage`.
